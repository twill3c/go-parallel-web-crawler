Go Parallel Web Crawler

See Go concurrency in action.

URL をひとつ渡すと、そのサイトの中を幅優先で巡回します。見どころはクロール結果ではなく、 goroutine で動く Worker が今なにをしているか、channel に何件が溜まっているか、 STOP で context が全 Worker に届くかです。

クロールの設定

idle

自分が管理するサイト、またはクロールが許可されているサイトで利用してください。 学習・デモ用の小規模クローラです(Workers ≤ 20・Max Pages ≤ 100・1 回 ≤ 60 秒・同一ドメインのみ・robots.txt は読みません)。
